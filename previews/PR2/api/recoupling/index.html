Recoupling API

Modules and generators

Kiwi.irrep_module — Function
irrep_module(rep::Irrep; basis = :lowering, T = Float64) -> IrrepModule

Explicit module for rep with matrices of the simple-root generators.

  • basis = :lowering — Kiwi's basis (see the conventions at the top of recoupling/modules.jl), for every simple Lie algebra.
  • basis = :gelfand_tsetlin — the Gelfand–Tsetlin basis (su(N) only).

T is the scalar type: Float64 or BigFloat give an orthonormal basis; Rational{BigInt} or Fp{P} give the exact, unnormalised lowering basis (with its Gram matrices).

Kiwi.generators — Function
generators(rep::Irrep; basis = :lowering, T = Float64) -> (E, F, H)

Matrices of the Chevalley generators Eᵢ, Fᵢ, Hᵢ (i = 1, …, rank) in the basis of irrep_module, as vectors of sparse matrices. They satisfy [Eᵢ, Fⱼ] = δᵢⱼ Hᵢ, [Hᵢ, Eⱼ] = Cⱼᵢ Eⱼ and the Serre relations; in an orthonormal basis Eᵢ = Fᵢᵀ. Basis vectors are ordered by weight (see basis_weights).

basis_weights(rep::Irrep; basis = :lowering) -> Vector{Vector{Int}}

The weight (Dynkin labels) of each basis vector of irrep_module, in order.

gt_patterns(rep::Irrep) -> Vector{Vector{Vector{Int}}}

All Gelfand–Tsetlin patterns of an su(N) irrep, as vectors of rows m[1], …, m[N].

Kiwi.fusion_tensor — Function
fusion_tensor(a, b, c; basis = :lowering, T = Float64, sparse = false)

Clebsch–Gordan coefficients C[i, j, k, μ] = ⟨a i; b j | c k; μ⟩ in orthonormal bases (TensorKit's fusiontensor layout): the intertwiner μ maps the basis vector k of V_c to Σᵢⱼ C[i, j, k, μ] eᵢ ⊗ eⱼ. For each μ the columns are orthonormal. Basis vectors are ordered as in basis_weights; the highest weight of each irrep comes first.

With sparse = true the same coefficients are returned as a SparseMatrixCSC of size (dim a · dim b) × (dim c · N), with row i + dim(a)·(j − 1) and column k + dim(c)·(μ − 1): the isometry V_c ⊗ ℂᴺ → V_a ⊗ V_b. Only entries with |C| > 1e-14 are stored.

With normalized = false (any scalar type, including Rational{BigInt} and Fp{P}) the result is the named tuple (C, gram_a, gram_b, gram_c, norms2) in the rational gauge: φ_μ(b_k) = Σᵢⱼ C[i, j, k, μ] bᵢ ⊗ bⱼ for the (unnormalised) module bases b, whose Gram matrices are gram_*, and ⟨φ_μ(v), φ_ν(w)⟩ = δ_μν norms2[μ] ⟨v, w⟩. With G = RᵀR (Cholesky) the unitary tensor is (R_a ⊗ R_b) C[:, :, :, μ] R_c⁻¹ / √norms2[μ].

Kiwi.fsymbol — Function
fsymbol(a, b, c, d, e, f; basis = :lowering, T = Float64, normalized = true)

The F-symbol (6j symbol) F^{abc}_d[e, f] in TensorKit's convention, an array of size (N^{ab}_e, N^{ec}_d, N^{bc}_f, N^{af}_d) relating the fusion trees ((a ⊗ b → e) ⊗ c → d) and (a ⊗ (b ⊗ c → f) → d).

  • normalized = true: unitary F-symbol. Floating-point T gives an Array{T, 4}; T = Rational{BigInt} gives exact entries as SqrtRational (any multiplicity).
  • normalized = false: the raw F-symbol in the rational gauge, for any T (including Fp{P}), as a named tuple (F, norms) with F::Array{T, 4} and norms = (nᵃᵇₑ, nᵉᶜ_d, nᵇᶜ_f, nᵃᶠ_d) the squared norms of the four vertices. Then F_unitary[μ, ν, κ, λ] = F[μ, ν, κ, λ] / √(nᵃᵇₑ[μ] nᵉᶜ_d[ν] nᵇᶜ_f[κ] nᵃᶠ_d[λ]).
source
Kiwi.rsymbol — Function
rsymbol(a, b, c; basis = :lowering, T = Float64, normalized = true)

The R-symbol R^{ab}_c[μ, ν] (TensorKit convention): the swap Va ⊗ Vb → Vb ⊗ Va maps the intertwiner μ of c → a ⊗ b to Σ_ν R[μ, ν] times the intertwiner ν of c → b ⊗ a (the vertex swap).

normalized = false returns (R, norms) in the rational gauge, for any T, with norms = (nᵃᵇ_c, nᵇᵃ_c) and R_unitary[μ, ν] = R[μ, ν] / √(nᵃᵇ_c[μ] nᵇᵃ_c[ν]). With T = Rational{BigInt} and normalized = true the entries are SqrtRational.

source
Kiwi.asymbol — Function
asymbol(a, b, c; basis = :lowering, T = Float64, normalized = true)

TensorKit's A-symbol A^{ab}_c = √(dim a dim b / dim c) · ϰ_a F^{ā a b}_b[1, c], reshaped to (N^{ab}_c, N^{āc}_b): it relates the vertex c → a ⊗ b to the vertex b → ā ⊗ c obtained by bending the leg a.

normalized = false returns, for any T, (A, norms, scale2) with A = ϰ_a · F_raw^{ā a b}_b[1, c] (rational gauge), norms = (n_cup, n_unit, nᵃᵇ_c, nᵃ̄ᶜ_b) (the vertices ā ⊗ a → 1, 1 ⊗ b → b, a ⊗ b → c, ā ⊗ c → b) and scale2 = dim a · dim b // dim c, so that A_unitary[μ, ν] = √scale2 · A[μ, ν] / √(n_cup · n_unit · nᵃᵇ_c[μ] · nᵃ̄ᶜ_b[ν]).

source
Kiwi.bsymbol — Function
bsymbol(a, b, c; basis = :lowering, T = Float64, normalized = true)

TensorKit's B-symbol B^{ab}_c = √(dim a dim b / dim c) · F^{a b b̄}_a[c, 1], reshaped to (N^{ab}_c, N^{c b̄}_a): it relates the vertex c → a ⊗ b to the vertex a → c ⊗ b̄ obtained by bending the leg b.

normalized = false returns, for any T, (B, norms, scale2) with B = F_raw^{a b b̄}_a[c, 1], norms = (nᵃᵇ_c, nᶜᵇ̄_a, n_cup, n_unit) (the vertices a ⊗ b → c, c ⊗ b̄ → a, b ⊗ b̄ → 1, a ⊗ 1 → a) and scale2 = dim a · dim b // dim c: B_unitary[μ, ν] = √scale2 · B[μ, ν] / √(nᵃᵇ_c[μ] · nᶜᵇ̄_a[ν] · n_cup · n_unit).

source
Kiwi.onej — Function
onej(a; basis = :lowering) -> Int

The 1j symbol ϰa = ±1 defined by `twoj(ā) = ϰa · transpose(twoj(a)). For self-conjugateathis is the Frobenius–Schur indicator; it always equals TensorKit's Frobenius–Schur phasesign(F^{a ā a}_a[1, 1])`. In the lowering basis it is computed once, in exact arithmetic, and cached per irrep.

source
Kiwi.twoj — Function
twoj(a; basis = :lowering, T = Float64, normalized = true)

The 2j symbol Z_a = √dim(a) · C^{a ā}_1[:, :, 1, 1], a real orthogonal matrix (rows: basis of a, columns: basis of ā) with Z_a[hw(a), lw(ā)] > 0.

normalized = false gives the cup in the rational gauge, for any T: a named tuple (X, norm2, gram_a, gram_abar) where X[i, j] are the coordinates of the (unnormalised) invariant vector of V_a ⊗ V_ā in the module bases, norm2 its squared norm and gram_a, gram_abar the Gram matrices of the bases. With G = RᵀR (Cholesky), Z_a = √dim(a) · R_a X R_āᵀ / √norm2.

source
Kiwi.threej — Function
threej(a, b, c; basis = :lowering, T = Float64) -> Array{T, 4}

The 3j symbol (a b c)[i, j, k, μ] = Σ_m C^{ab}_{c̄}[i, j, m, μ] Z_c[k, m] / √dim(c), an invariant tensor of V_a ⊗ V_b ⊗ V_c normalised to Σ |·|² = 1 for each multiplicity label μ of a ⊗ b → c̄. For su(2), wigner3j(j₁, j₂, j₃) = (−1)^{j₁−j₂−j₃} · threej.

source
Kiwi.SqrtRational — Type
SqrtRational

An exact real number s · √q with s ∈ {−1, 0, 1} and q ≥ 0 rational, the form taken by multiplicity-free recoupling coefficients in exact arithmetic.

TensorKit and caches

Kiwi.tensorkit_sector — Function
tensorkit_sector(g::LieAlgebra) -> Type
tensorkit_sector(r::Irrep) -> sector

The TensorKitSectors.jl sector type of the irreps of g, and the sector of an irrep. Its Nsymbol, Fsymbol, Rsymbol, fusiontensor, dim, dual and frobenius_schur_phase are Kiwi's nsymbol, fsymbol, rsymbol, fusion_tensor, dimension, conjugate and onej (lowering basis, Float64). Irrep(s) converts back.

Available after using TensorKitSectors (or TensorKit), through a package extension.
